A SMALLER LAUNCHER. A CLEARER WORKFLOW.

Everything around your next project.

A practical toolkit for the work between opening an engine and shipping a project.

01

Make room for every engine.

Find installed Unreal Engine versions, choose components, and install, verify, modify or remove an engine. Large-file checks can run in parallel while applying updates, with progress inside the current file.

  • Automatic discovery in common folders and Windows Registry
  • Component selection and clear warnings for optional Epic global registration
  • Access is checked before fresh installs, updates and resumes. If a mandatory Epic registration record needs UAC, a temporary headless helper handles only that record; the app and Epic session stay in your user profile. Canceling preserves the saved task. Protected engine folders need a writable location or corrected permissions; read-only and sharing errors are reported separately.
  • The engine-registration check can request a temporary UAC helper for Epic’s shared metadata only. The app keeps your normal user profile; engine files and folder permissions are unchanged.
02

Your projects, already there.

Manage project scan folders and refresh the saved locations, including their subfolders, with visible progress and Stop. Completion uses a brief notification.

  • Installed engines and projects in one place
  • Use the registered .uproject file association
  • Created and discovered projects are recorded wherever they are saved. Stopping keeps projects found so far; no background watcher is used. Registration errors are reported separately.
03

Give your content a home.

Sign in to Epic, browse your Fab library, connect an existing Epic VaultCache, and work with your local Vault.

  • Download assets, projects and plugins
  • Content updates with conflict review
  • Seven local sort orders: name A–Z/Z–A, asset type, UE newest/oldest and downloaded/not downloaded first. Choose page size below the library.
  • Full projects are recognized from the selected package files. Reuse the Vault download and choose a new folder to create one.
04

Put downloads in order.

Queue asset downloads to Vault with one active transfer. Reorder waiting items by dragging or using keyboard controls; project copying stays a separate action.

  • Restored queues wait for your start; a manually resumed download is shown once.
  • Damaged partial blocks are checked and fetched again; checking, copying and rollback show real progress.
05

Epic access, through Epic.

Enter a key or import a TXT batch in the app. Preview the products and Epic account, then confirm redemption explicitly. The official Epic window stays a separate fallback.

  • If authorization expires, sign in again without discarding saved tasks or the queue.
  • Saved sessions protected by Windows DPAPI
  • Three columns: key suffix, product title, and status with a reason.
  • A two-second pause between keys, Stop after the current key, and no automatic retry of unknown results. Keys are not passed to the official window.
06

Keep your workspace local.

Catalogue data, covers, preferences and download history are stored locally. Interface translations need no network connection.

  • Installed and portable packaging options
  • Light or dark app theme, saved preferences and system tray controls.
  • Blank-area context menus are suppressed; editable fields and custom app menus keep their actions.
  • Navigation, account and window controls in one integrated header.
07

App updates, on your terms.

Get signed Unreal Manager updates from GitHub Releases for installed and portable copies.

  • Check at startup at most once a day, or manually, with stable and beta channels.
  • Verified packages, saved tasks and recovery for interrupted app updates.
  • A temporary helper waits for the new interface before confirming completion; no permanent update service.

SMALL BY DESIGN

The launcher should leave room for the engine.

A Rust backend and a Tauri desktop interface, with no game storefront. Build tools stay on the developer's machine.

Software-rendering arguments are passed to every WebView2 window through its API, including Epic sign-in and redemption. Actual GPU activity requires measurement.
