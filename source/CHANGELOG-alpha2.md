# Историческая запись изменений alpha.2

Эта запись описывает раннюю итерацию и сохранена для истории. Упомянутые ниже
возможности и проверки относятся к тому этапу; они не подтверждают новую
проверку beta.6. Текущее описание приложения находится в [README.md](README.md).

- Вход Epic в отдельном окне официального сайта с автоматическим возвратом. Ручное копирование кода удалено; полный новый сценарий ожидает проверки пользователем.
- Сохранение сеанса Windows DPAPI: токены зашифрованы для текущего пользователя, не передаются в UI и не записываются в журналы.
- Восстановление сеанса, выход и удаление только собственных сохранённых данных входа.
- Реальный API библиотеки Fab для Unreal Engine, загрузка всех страниц, дедупликация, поиск и фильтры по типу/версии UE. 50 строк на страницу интерфейса.
- Ошибки доступа, сети, формата и незавершённой пагинации не выдаются за пустую или успешно загруженную библиотеку.
- Раздел «Активировать ключ»: официальная страница Epic в браузере, затем обновление библиотеки. Ключ вводится и подтверждается на стороне Epic.

На описанном этапе реальное подключение аккаунта требовало входа пользователя. До входа получение его библиотеки не считалось проверенным. Показывались только материалы библиотеки Unreal Engine; остальные форматы Fab не охватывались этим API. Скачивание и установка ассетов тогда ещё не были реализованы.

Интеграция использовала egs-api 0.14.0 для авторизации и отдельный запрос страниц Fab с явной обработкой ошибок. Лицензия MIT и уведомление egs-api сохранены в [src/licenses.json](src/licenses.json). API Fab для сторонних клиентов не имеет гарантии стабильности.

В записи упоминались тесты формата одноразового кода, Windows DPAPI и повреждённого шифротекста, разбора материалов, пагинации с кодированием курсора и дубликатами, отказа на второй странице и повторяющегося курсора.


## Fab Vault
Позднее в эту историческую запись добавлены загрузка материалов с выбором версии,
локальный Vault, прогресс, проверка SHA-1 и установка в проект без перезаписи
конфликтующих файлов. Отдельный отчёт о тогдашней проверке в репозиторий не включён;
он не используется как подтверждение текущей проверки. Порядок актуальных проверок
описан в [verification/README.md](../verification/README.md).
